# Katılımcı kurulum talimatı

1. Bu bağlantıdan zip'i indirin: **[GitHub Release bağlantısı — ekip dolduracak]**
2. Zip'i bir klasöre çıkarın (masaüstü olabilir; klasörü silmeyin).
3. Chrome'da adres çubuğuna `chrome://extensions` yazın.
4. Sağ üstteki **Geliştirici modu** düğmesini açın.
5. **Paketlenmemiş öğe yükle** → çıkardığınız klasörü seçin.
6. Sağ üstteki yapboz simgesi 🧩 → **Smarter Prompt**'u sabitleyin.
7. Simgeye sağ tıklayın → **Seçenekler** → **"Araştırmaya katılmayı kabul ediyorum"** kutusunu işaretleyin.
   Sayfadaki katılımcı kodunu (8 karakter) bize iletin.
8. chatgpt.com, claude.ai veya gemini.google.com'a gidin. Sağ altta **✨ Geliştir** butonunu görmelisiniz.

Kullanım: Kısa bir prompt yazın → **✨ Geliştir** (veya **Ctrl+Shift+E**) → bir kart seçip **Kullan** →
isterseniz düzenleyin → kendiniz gönderin. **Geri al** ilk yazdığınız metne döner.
